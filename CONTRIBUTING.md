# Contributions

This repository is published so the source can be read and so installers can be downloaded. It is **not** an open-source project and it does **not** accept contributions.

Please do not:

- open issues
- open pull requests
- send patches
- fork this as a place to send changes back

Issues and pull requests from outside collaborators are closed.

If you found a security problem, use **Security → Report a vulnerability** (private advisory). There is no bounty and no SLA.
