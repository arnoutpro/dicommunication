Arnout.pro Dicommunication

This installs Dicommunication as a background service. It starts with this Mac, needs nobody to be logged in, has no window, and you open it in a browser.

  • It runs as its own account, _dicommunication, and keeps its data in /Library/Application Support/Dicommunication.
  • It always asks for sign-in. You create the first administrator after the installation.
  • By default only this Mac can connect, on port 8080. You can change that afterwards.

An old Dicommunication.app in Applications (versions up to 0.12) is replaced by this service. Its settings are not carried over: export them first with Configuration > Import / export.
