Installed

The service is running. Open http://localhost:8080/ in a browser on this Mac (or the Dicommunication shortcut in Applications). The first visit goes to Setup, where you create the first administrator.

In Terminal:

sudo dicommunication service status
sudo dicommunication service create-admin NAME
sudo dicommunication service network on     # let other computers connect (HTTPS)
sudo dicommunication service port 8090
sudo dicommunication service uninstall

If something does not work: /var/log/dicommunication/service.log and /var/log/dicommunication-install.log.
