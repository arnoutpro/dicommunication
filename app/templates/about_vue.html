What this application is

{{ product_name }} is a Study Root C-FIND workstation aimed at Philips Vue PACS. Query stored studies at Study, Series, or Image, including optional Tamar / ELSCINT1 private tags. List Structured Report series (modality SR) from those studies, then C-MOVE the report objects to this AE and read the DICOM Content Sequence. It is not a PACS, not a viewer, not Modality Worklist, and it does not use a language model to read reports.

The Dicommunication MSI installs this tool next to the network workstation. Both use the same config.json. There is no web login — treat the UI like a diagnostic console on the PACS VLAN.

Open Help for query keys, hierarchical FIND, and Vue private tags.
