What this application is

Dicommunication is a trusted-network DICOM and HL7 connectivity workstation for IT staff and PACS administrators. Configure this computer as a DICOM Application Entity, register remote nodes (PACS, Orthanc, RIS/MWL, modalities), optionally impersonate extra calling AE Titles, and run the checks a connectivity ticket actually needs.

It is written by arnout.pro (Arnout). The web UI is FastAPI + HTMX. DICOM uses pynetdicom / pydicom. The Windows and macOS installers run it as a background service that you open in a browser; Docker Compose and a local Python process serve the same UI in a browser at http://127.0.0.1:8080.

This is not a PACS, not an image viewer, and not a replacement for a vendor modality simulator. It does not store a clinical archive. The web UI asks for a sign-in as soon as the first account exists or other computers can reach it (see Configuration → Security); until then treat it like a diagnostic console on this computer.

Open Help for how each screen and tool works, including C-ECHO versus C-STORE versus Study Root C-FIND versus Modality Worklist, and HL7 send to Vue / IS Link.

What it does and does not do

It does It does not
Present a calling AE Title (this workstation, or a virtual identity such as CT1) Use C-GET. Every retrieve is a C-MOVE to this workstation's own Storage SCP (Accept C-STORE must be on, and this AE must be a C-MOVE destination on the PACS)
Associate with a remote AE and show which SOP Classes were accepted or rejected Keep an archive of clinical images (retrieved images are held in memory for a run; the Anonymizer writes where you tell it)
Send Verification (C-ECHO), a tiny Secondary Capture (C-STORE), Encapsulated PDF Storage (PDF to DICOM), Study Root Query/Retrieve C-FIND (Study / Series / Image), and Modality Worklist C-FIND Speak DICOM TLS (DICOM and HL7 traffic to the PACS is not encrypted)
Optionally serve a local web worklist as an MWL SCP, and optionally accept C-STORE (what a PACS moves here for Analytics, the Anonymizer, the Cleaner, the Router and the Tag Editor), on the listen port Parse, validate, or map HL7 fields — paste a message and send it
Send an HL7 v2 message over TCP (MLLP by default) to a host:port Promise that an HL7 ACK updated the PACS — ACK only means the listener accepted the bytes
